# Context Vibes Organization Configuration (`.github` Repository)

This special `.github` repository holds default community health files and configurations for the Context Vibes GitHub organization.

## Contents

*   **`profile/README.md`**: This is the main README that appears on the Context Vibes organization's GitHub page ([https://github.com/contextvibes](https://github.com/contextvibes)).
*   **`CONTRIBUTING.md`**: Default guidelines for contributing to projects within the Context Vibes organization. Individual repositories may have their own more specific `CONTRIBUTING.MD`.
*   **`CODE_OF_CONDUCT.md`**: The Code of Conduct applicable across all Context Vibes community spaces.
*   **`SECURITY.MD`**: Instructions on how to responsibly report security vulnerabilities for Context Vibes projects.
*   **`SUPPORT.MD`**: Information on how to get support for Context Vibes projects.
*   **`FUNDING.yml`**: Configuration for the "Sponsor" button, if applicable.
*   **`ISSUE_TEMPLATE/`**: Default templates for creating GitHub Issues.
*   **`PULL_REQUEST_TEMPLATE.md`**: Default template for Pull Request descriptions.

These files provide a baseline for repositories within the organization. Individual repositories can override these defaults by including their own versions of these files in their own `.github` directory or root.

For information about the Context Vibes initiative itself, its mission, and projects, please see the [main organization profile README](https://github.com/contextvibes/.github/blob/main/profile/README.md) or visit [https://github.com/contextvibes](https://github.com/contextvibes).
