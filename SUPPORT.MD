# Getting Support for Context Vibes Projects

Thank you for using and contributing to the Context Vibes initiative! Here's how you can get support:

## Documentation

Please check the `README.MD` and any `docs/` folder within the specific project repository you are interested in.
*   **ContextVibes CLI:** [https://github.com/contextvibes/cli](https://github.com/contextvibes/cli)
*   **THEA Guidance System:** [https://github.com/contextvibes/THEA](https://github.com/contextvibes/THEA) 
      *(User: Update this if THEA moves to its own org/URL)*

## Community Discussions

For general questions, ideas, or to share how you're using our tools, please join our community discussions:
*   **Context Vibes Organization Discussions:** [https://github.com/orgs/contextvibes/discussions](https://github.com/orgs/contextvibes/discussions) 
      *(User: Verify this link or replace with your primary community forum URL)*

## Reporting Bugs or Requesting Features

*   **For the `ContextVibes CLI`:** Please use the [Issues Page](https://github.com/contextvibes/cli/issues) in the `contextvibes/cli` repository.
*   **For the `THEA` Guidance System:** Please use the Issues Page in the `contextvibes/THEA` repository.
      *(User: Update this if THEA moves or has a different issue tracker)*
*   For other projects, please check their specific repositories for issue tracking information.

When reporting a bug, please include as much detail as possible, including steps to reproduce, your environment, and versions of relevant software.

## Security Vulnerabilities

Please do NOT report security vulnerabilities through public GitHub issues. Refer to our [Security Policy](./SECURITY.MD) for information on how to report them privately.

We appreciate your engagement with the Context Vibes community!
